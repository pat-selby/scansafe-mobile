Do

  • Use green, amber and red only to communicate a scan verdict.
  • Render every URL and rule output in the monospace stack.
  • Pair every verdict colour with an icon and a text label.
  • Keep plain English visible by default, technical detail one tap away.
  • Let cards breathe — 16px padding minimum, even when it costs a scroll.

Don't

  • Don't make a scanned URL tappable. The app explains links; it never opens them.
  • Don't add shadows, glows, or pulsing borders to convey risk.
  • Don't use accent green for a disabled, neutral, or decorative element.
  • Don't write a finding that could apply to any URL — name the pattern detected.
  • Don't introduce a second accent hue.
  • Don't set body copy in a verdict colour.
